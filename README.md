# Birthday For Her ❤️

A mobile-first interactive birthday surprise inspired by the reference video you provided.

## Included screens
1. Opening gift
2. Secret 3-digit code
3. Birthday cake celebration
4. Balloon popping mini-game
5. Photo/memory section
6. Tap-to-reveal message
7. Personal birthday letter

## Change her name and secret code
Open `app/page.js` and edit:

```js
const CONFIG = {
  herName: "Beautiful",
  secretCode: "0200",
  letter: "Your personal message..."
};
```

## Change photos
Put these four files in `public/photos/`:

- photo1.jpg
- photo2.jpg
- photo3.jpg
- photo4.jpg

The website automatically uses them.

## Run
```bash
npm install
npm run dev
```

Then open:
http://localhost:3000

## Deploy
This is a frontend-only project. It does not need a database or backend.
You can deploy it to Vercel after testing locally.
